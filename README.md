## Descripción
Página web sobre nueve deportes (fútbol, baloncesto, voleibol, béisbol, natación, atletismo, tenis, ciclismo y boxeo), con reglas básicas, tabla comparativa, deportistas ecuatorianos, hábitos de salud y glosario. Incluye partes interactivas hechas con JavaScript (menú, filtro, quiz, test, buscador y modo oscuro).

## Estructura de la carpeta
- `index.html`: página principal.
- `estilos.css`: estilos de la página.
- `script.js`: partes interactivas (extra).
- `imagenes/`: logo, portada y dibujos de los deportes.

## Cómo abrirla
Abrir `index.html` con un navegador (doble clic). Las rutas son relativas, así que la carpeta debe mantenerse completa.
